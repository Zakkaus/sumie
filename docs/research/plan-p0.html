二目標與定位

目標（依優先序）

  1. 字型清晰度：分數縮放下不輸 Ghostty
  2. CJK：寬度、字形、對齊都正確，中文和英文一樣清楚
  3. 輸入法：fcitx5 與 IBus 組字、選字、候選字視窗位置都正確，組字時快捷鍵照常生效
  4. UX 與易用性：不改設定就能用，快捷鍵沿用主流，所有操作找得到
  5. 多 agent 工作流：多視窗、分頁、分割、agent 狀態總覽
  6. 通用：任何實作標準協定的 Wayland 合成器，NVIDIA、AMD、Intel、Apple GPU 都能跑

非目標

  • X11：永遠不做，程式裡不留 X11 路徑
  • 第一版不做、但架構留後路：macOS、Windows、sixel、Lua、外掛
  • macOS、Windows：綁平台的只有視窗與輸入法、字型、GPU、PTY 四個 crate，核心不碰平台 API；不先替沒有的平台寫抽象介面
  • Lua 和外掛：所有操作走同一層有名字的指令，用 sumie cli 經 Unix socket 呼叫；日後的外掛呼叫同一層
  • sixel：libghostty-vt 1.0.1 沒有 sixel 解析，只有裝置屬性回報用的代碼（device.h:40）；圖片先支援 kitty graphics

通用，不是只為自己

  • 只用標準 Wayland 協定，不呼叫 KWin 專屬介面。缺協定就退回：沒有 fractional-scale 用整數縮放；沒有 xdg-decoration（GNOME）就自己畫標題列（P4）。
  • 輸入法只走 text-input-v3，同一份程式涵蓋 KWin 加 fcitx5、GNOME 加 IBus、wlroots 加 fcitx5。
  • 預設值給一般使用者：系統 monospace 字型、跟隨系統深淺色、介面有英文、繁中、簡中。你的 JetBrains 字型、Cobalt2 配色、VSCode 分流寫在你的 ~/.config/sumie/sumie.toml。
  • 連結分流做成設定規則，預設交給 xdg-open；path:line 預設用 $VISUAL 或 $EDITOR。
  • agent 狀態只讀標準訊號，不為 Claude Code 寫特例。
  • 建置對發行版友善：系統有 libghostty-vt 就用 pkg-config，沒有就用 vendored 選項。
  • 驗證範圍：P0 到 P3 在 KWin 上做；P4 加測 GNOME、Sway 或 Hyprland、IBus。GPU 有三家可測：桌機的 NVIDIA 與 AMD 610M、MacBook 的 Apple GPU。

4.4 執行緒與資料流

主執行緒（calloop 事件迴圈）
 ├─ Wayland 事件：鍵盤、滑鼠、輸入法、縮放、焦點
 ├─ 按鍵 ──▶ 比對快捷鍵 ──▶ 沒命中才經 sumie-vt 編碼 ──▶ 寫 PTY（非阻塞，寫不下就排隊）
 └─ frame callback ──▶ 有變化的窗格：鎖 terminal → render state begin_update → 解鎖 → 畫
每個窗格一條 PTY 讀取執行緒
 └─ read ──▶ 鎖 terminal ──▶ 餵 vt ──▶ 解鎖 ──▶ eventfd 通知主執行緒

libghostty-vt 的 render state 分兩段：begin_update 要持有 terminal 的鎖，end_update 不用（render.h:673-704），所以鎖只在複製狀態那一刻持有。P0 在主執行緒繪製；觸發條件：多窗格時延遲或幀節奏的門禁不過，再把繪製移到每個視窗自己的執行緒（Ghostty 的做法）。

4.11 語言與依賴：不是純 Rust

sumie 自己的程式碼全部是 Rust。底層的驅動、視窗系統與字型設定本來就是 C，任何終端機都一樣；unsafe 只出現在包裝這些函式庫的 crate（見 13.4）。

六CJK

一個字元進來
 ├─ 寬度：libghostty-vt 的 Unicode 寬度與字素叢集（mode 2027）
 │    ├─ CJK 表意文字、假名、全形標點 = 2 格
 │    └─ 東亞歧義寬度（○ ※ ① ─）預設 1 格，與 glibc wcwidth 一致；可設定為 2 格
 ├─ 字形：fontconfig 依語言標籤選後備字型
 │    zh_TW → 繁體字形 · zh_CN → 簡體字形 · ja → 日文字形；設定可覆寫
 │    本機實測：JetBrainsMono Nerd Font + lang=zh-tw 的第二順位是 Noto Sans CJK TC
 ├─ 大小：塞進 2 格寬；原尺寸放得下就不縮放，保留 hinting
 ├─ 垂直：依字元格置中，基線與英文字型對齊，不偏上、不被切

 └─ 游標、選取、刪除、標題截斷：以整個寬字元為單位
風險處理
Ghostty 對被縮放或限寬的字形關掉 hinting（freetype.zig:361），CJK 字形常走這條路，可能比英文軟原尺寸放得下就不縮放；P0 關卡 A 專門放筆畫密的繁體字對比
終端機和程式算出的寬度不同，排版就會錯位（Claude Code 的框線、表格）歧義寬度預設 1 格；P0 核對 Claude Code 用的寬度算法是否一致
同一個漢字在繁、簡、日字型裡寫法不同依 locale 選字型，不寫死某一套 CJK 字型
CJK 字型的上下緣比英文字型高，行高被撐大或字被切行高由主字型決定，CJK 在格內置中；P0 截圖檢查

P0 關卡 A 的測試文字固定一份：英文與程式碼、體鬱龍讀繁 這類筆畫密的字、全形標點 ，。「」『』、歧義寬度 ○※①─、假名、emoji 與 ZWJ 序列、Nerd Font 圖示、Claude Code 的框線字元。另外用一套非 Noto 的 CJK 字型（例如霞鶩文楷）再跑一次，確認後備邏輯沒有寫死字型。

八UX、外觀、設定與上手

  • 不改設定就能用：沒有設定檔也是完整可用的終端機。
  • 快捷鍵與行為照主流終端機，不自創；和主流不同的地方寫明理由。
  • 所有操作都能在命令面板搜到，旁邊顯示快捷鍵，不必背。
  • 每個動作都有回饋：複製後短暫提示字數，設定有錯在視窗內說明錯在哪一行。
  • 介面元件全鍵盤可操作、焦點可見；兩種主題的文字與元件對比都達 WCAG AA。
  • 介面文字放 locale 檔（en、zh-TW、zh-CN），不寫死在程式裡。

10.3 門禁

  • 數字寫進棘輪檔，比檔案高或低都失敗；變好時同步調低檔案裡的數字。
  • 洩漏門禁：在無頭巢狀 KWin 開關 200 個視窗與窗格，fd 數與記憶體持平。沿用 ~/om/lab/wezterm-window-leak/scripts/headless.sh 的做法。
  • 停幀門禁：多個窗格持續輸出、連續數小時，KWin 不停幀。
  • cli 浸泡（P3 起）：每秒呼叫一次 sumie cli list，6 分鐘內記憶體持平，對照 WezTerm 的 37 → 87 MB。
  • 多日浸泡：20 個窗格持續輸出、定時開關視窗、跑 24 小時以上，fd、記憶體、GPU 映射持平；桌機與 MacBook 各跑一次。
  • 測試時限和各層門禁的執行時機寫進 REQUIREMENTS.md；P0 只量基準，不設門禁。

13.2 結構規則

  • 介面定義在使用方：sumie-core 宣告它需要的能力，平台 crate 實作；用編譯期斷言把實作釘在介面上，介面一變就編譯失敗。core 因此能在沒有 Wayland、沒有 GPU 的環境下測試。
  • 介面旁寫明不許做什麼：不許在哪個執行緒呼叫、最多阻塞多久、呼叫次序、不承擔哪些職責。
  • 邊界的方法簽名不預先寫死：計畫只列每個邊界必須承載的行為與約束，簽名在呼叫點定案後寫回架構文件。
  • 新增 crate 或模組之前先改架構文件，寫明它管什麼、允許什麼、禁止什麼。禁止名為 util、common、helper、misc 的模組。

13.4 Rust 規範

  • edition 2024。rust-version 定 1.96（libghostty-rs 的下限），不超過 Gentoo 穩定版的 rust（目前 amd64 與 arm64 都是 1.98.1），發行版才能直接打包；提高下限要寫理由。本機 1.99，上游穩定版 1.100.0（2026-11-12）。
  • [workspace.lints] 統一 lint：clippy 的 all 與 pedantic 設為 warn，CI 用 -D warnings 擋下。
  • unsafe 只允許在 sumie-vt、sumie-font、sumie-render（FFI 與 GL）；其他 crate 一律 #![forbid(unsafe_code)]。每個 unsafe 區塊寫 // SAFETY: 說明前提（undocumented_unsafe_blocks）。
  • FFI 優先用現成 crate（freetype-rs、HarfBuzz 綁定、fontconfig），沒有才用 bindgen；一律是 -sys 加安全包裝。
  • 錯誤：函式庫 crate 用 thiserror 定義錯誤型別；不吞錯誤。外部輸入（設定檔、命令列、cli 請求）在邊界驗證一次，之後信任型別；不寫用不到的防禦、重試、旗標。
  • 日誌用 tracing，等級照真實意義。絕不記錄使用者輸入、終端輸出、剪貼簿內容，因為終端機會經手密碼；只記事件與長度。
  • 依賴：每加一個要寫理由；cargo-deny 檢查授權與安全公告；cargo-machete 找沒用到的依賴。
  • 註解用英文，只寫程式看不出的約束、取捨與安全前提。

13.6 現代化

「現代」照你的規則定義：每個選型對照當天抓的來源並附連結（第十五節），開工當天再核一次版本。

  • 標準庫有的就不引套件：std::sync::LazyLock 取代 lazy_static 與 once_cell；用 edition 2024 的 let chains；錯誤用 thiserror 2；日誌用 tracing，不用 log。
  • 不引入 async 執行環境（tokio）：終端機只有少數 fd，calloop 事件迴圈加每個窗格一條讀取執行緒就夠；async 會把取消與生命週期問題帶進每一層。觸發條件：sumie-mux 要同時服務多台機器的連線時再評估。
  • 依賴：[workspace.dependencies] 統一版本；Cargo.lock 入庫；cargo-deny 擋重複版本、已知漏洞與授權衝突；大版本升級各自一個提交，過全部門禁才合併。
  • 排程 CI 用 rust-version（1.96）與最新穩定版各建置一次，確認下限沒有被不知不覺拉高。
