# Icons

The sumie icon is the hiragana く from Yuji Syuku, a brush typeface that Kinuta Font Factory digitized from calligrapher Yuji Kataoka's lettering. The SVGs contain the glyph outline only, not the font.

Yuji Syuku is licensed under the SIL Open Font License 1.1 ([OFL-YujiSyuku.txt](OFL-YujiSyuku.txt)); source: https://github.com/google/fonts/tree/main/ofl/yujisyuku. OFL FAQ §1.1 permits logos made from glyph outlines without placing the artwork under the OFL.

| File | Use |
| --- | --- |
| `hicolor/scalable/apps/sumie.svg` | Linux application icon (freedesktop hicolor theme) |
| `hicolor/symbolic/apps/sumie-symbolic.svg` | Single-colour icon for 16 px panels |
| `macos/sumie.svg` | macOS app icon master on the 1024 px grid |
